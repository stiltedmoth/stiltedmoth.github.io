Elementorum

A 2.5D action game, where the player can create unique spells by combining elements from their environment. The project was made in the Unity engine, using WWise for audio and Jira for project management.

For this project I worked on both Gameplay and Graphics programming, rapidly prototyping as the concept for the game developed, then further developing game systems and working with our team's artists and Unity's shader pipeline to achieve the game's visual style.

Developed with Hydrabyte for Abertay's DES315 module - some of my teammates took the game on to Dare Academy, which you can find here!

Instanced Grass

A 3D environment constructed using DirectX11, making use of Instanced draw calls to performantly render a high quantity of grass. Features a HLSL lighting shader implementation supporting Point, Spot, and Directional lights, terrain using a heightmap and dynamic plane tesselation, grass wind emulation using a geometry shader, and toggleable post-processing effects including a bloom compute shader.

Multiplayer Brawler

A local multiplayer versus game developed in SFML, with a fast-paced gameplay loop where players alternate between fighting to the death and replacing and upgrading their abilties, putting together unique and powerful combinations.

The project was developed in two stages, a groupwork portion and an individual extension. I developed many aspects of the project, including multiplayer input handling, graphics and animation programming, and gameplay systems such as hit detection and response, with my individual extension supplementing the project with additional gamemodes, a sandbox environment, and many more abilties. The custom ability animations system was implemented using function pointers for animation events, to allow for streamlined development of new abilities.
